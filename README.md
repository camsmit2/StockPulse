# 📈 Team StockPulse - Real-Time Stock Monitor

## Overview
This project is a real-time stock monitoring application built using C#. It uses Task Parallel Library (TPL) for concurrent data fetching and LINQ for data analysis.

## Features
- Real-time stock updates
- Parallel data fetching
- Sorting and filtering using LINQ
- Top gainers and losers display

## Technologies
- C#
- .NET
- Task Parallel Library
- LINQ
